# 实验二：语法分析程序（LL(1)）

> 导航：[仓库首页](../README.md) · 当前：实验二说明 · [C++ 实现](cpp/README.md) · [Python 实现](python/README.md)

## 实验题目

编写一个语法分析程序：对词法分析得到的 Token 序列做语法分析，输出语法分析树；
若采用自顶向下方法，还需给出推导（产生式）序列。句子（文法）由自己定义，并要求包含错误处理。

| 项目 | 要求 |
|---|---|
| 输入 | 字符流（内部先经词法分析得到 Token 序列） |
| 输出 | 语法分析树；自顶向下方法还需给出推导序列 |
| 文法 | 自定义句子的文法 |
| 错误处理 | 分析表查不到、终结符不匹配、输入多余时给出错误位置与期望符号 |

本实验采用 **LL(1)** 方法：先构造预测分析表，再用显式栈完成无回溯的自顶向下分析。

## 文法

处理的句子是算术表达式。原始文法含左递归，消除左递归后为：

```text
E  -> T E'
E' -> + T E' | - T E' | ε
T  -> F T'
T' -> * F T' | / F T' | ε
F  -> ( E ) | id | num
```

该文法满足 LL(1) 条件：同一非终结符各候选式的 FIRST 集两两不交，含 ε 的候选式的
FOLLOW 集与其余候选式的 FIRST 集不相交。

## FIRST / FOLLOW 集

| 非终结符 | FIRST | FOLLOW |
|---|---|---|
| `E` | `( id num` | `) $` |
| `E'` | `+ - ε` | `) $` |
| `T` | `( id num` | `+ - ) $` |
| `T'` | `* / ε` | `+ - ) $` |
| `F` | `( id num` | `* / + - ) $` |

## LL(1) 预测分析表

| | ID | NUM | PLUS | MINUS | TIMES | OVER | LPAREN | RPAREN | EOF |
|---|---|---|---|---|---|---|---|---|---|
| **E** | E→TE' | E→TE' | | | | | E→TE' | | |
| **E'** | | | E'→+TE' | E'→-TE' | | | | E'→ε | E'→ε |
| **T** | T→FT' | T→FT' | | | | | T→FT' | | |
| **T'** | | | T'→ε | T'→ε | T'→\*FT' | T'→/FT' | | T'→ε | T'→ε |
| **F** | F→id | F→num | | | | | F→(E) | | |

## 输出

- **产生式序列**：按最左推导的展开顺序编号输出；
- **语法分析树**：以缩进树形输出，终结符带词素（如 `ID (a)`），空产生式显示 `epsilon`。

## 文法假设

- 只处理表达式，不含赋值语句、`if`/`repeat` 语句与语句序列；
- 表达式必须完整，分析完须到达输入末尾；
- 采用“遇错即停”策略，一次报告第一个错误。
