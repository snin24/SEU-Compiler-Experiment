# 简易词法分析器：关键字与完整词法单元清单

## 1. 关键字（Keywords）

关键字共 8 个，全部使用小写形式。

| 词素（Lexeme） | Token 类型 |
|---|---|
| `if` | `IF` |
| `then` | `THEN` |
| `else` | `ELSE` |
| `end` | `END` |
| `repeat` | `REPEAT` |
| `until` | `UNTIL` |
| `read` | `READ` |
| `write` | `WRITE` |

关键字必须在识别出完整标识符后，通过查询关键字表进行区分。

例如：
- `if` → `IF`
- `ifx` → `ID`
- `write` → `WRITE`
- `writer` → `ID`

## 3. 词法规则说明

### 3.1 标识符（ID）

标识符的正则表达式为：

```regex
[a-zA-Z_][a-zA-Z0-9_]*
```

规则：
- 首字符必须是英文字母或下划线。
- 后续字符可以是英文字母、数字或下划线。
- 标识符区分大小写。
- 识别完整标识符后，查询关键字表，确定最终 Token 类型。

示例：

| 输入 | Token 类型 |
|---|---|
| `x` | `ID` |
| `count1` | `ID` |
| `example_id` | `ID` |
| `_temp` | `ID` |
| `if` | `IF` |
| `ifx` | `ID` |

### 3.2 整数（NUM）

正则表达式：

```regex
[0-9]+
```

只支持非负整数，不支持小数、科学计数法或带符号数字。

示例：`0`、`123`、`45678`。

负数由 `MINUS` 和 `NUM` 两个 Token 表示。例如，`-123` 输出为：

```text
(MINUS, "-")
(NUM, "123")
```

### 3.3 赋值运算符（ASSIGN）

赋值运算符为：

```text
:=
```

必须将其识别为一个完整 Token：

```text
(ASSIGN, ":=")
```

### 3.4 关系运算符（RELOP）

支持以下六种关系运算符：

```text
=  <>  >  <  >=  <=
```

它们统一归类为 `RELOP`，并保留原始词素。

例如：

```text
(RELOP, ">=")
(RELOP, "<>")
(RELOP, "=")
```

识别时应优先考虑双字符运算符，避免将 `>=` 错误拆分为 `>` 和 `=`。

### 3.5 单字符运算符与分隔符

| 词素 | Token 类型 |
|---|---|
| `+` | `PLUS` |
| `-` | `MINUS` |
| `*` | `TIMES` |
| `/` | `OVER` |
| `(` | `LPAREN` |
| `)` | `RPAREN` |
| `;` | `SEMI` |

### 3.6 空白字符

空格、制表符、换行符和回车符用于分隔词素。

它们不产生实际输出 Token，词法分析器应直接跳过。

## 4. 错误处理要求

遇到不属于任何合法词法单元的字符时，应报告词法错误，并指出非法字符及其位置。

例如：

```text
x := 10 @ 20
```

字符 `@` 不符合任何已定义的词法规则，应报告错误，而不能静默忽略。
